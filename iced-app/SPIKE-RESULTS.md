# Fase 0 spike results (libcosmic rev 60ad2cc)

Tested with the headless harness (nested `cosmic-comp` + grim, `gnome-shell --headless` + extension, Xvfb + openbox)
and, for S1/S4, briefly on the real COSMIC session (fractional scale 1.25, NVIDIA).

| Spike | Result |
|---|---|
| S1 COSMIC overlay | **Pass.** `get_layer_surface` (Overlay, 4 anchors, `Exclusive` keyboard, size `(None,None)`, `exclusive_zone -1`) created per show, `destroy_layer_surface` on hide; app stays alive with zero windows (`no_main_window`). Surface size comes from `window::Event::Opened{size}` (no `Resized` is sent for layer surfaces). Card follows the first `mouse_area::on_move`; bottom-center fallback after 150 ms; click outside (outer `mouse_area` + inner capturing `mouse_area`) and Escape close; `text_input::focus` must be issued **after** the surface exists (on first pointer/opened event) or typing is ignored. libcosmic auto-blurs layer surfaces over the whole output: call `core.set_auto_blur(Auto::Popup \| Auto::System)` and use `blur::blur` with the card rect only (seen on the real session: whole screen blurred). |
| S2 GNOME window | **Pass.** `window::open` + `set_window_title("Clipboard History Popup")` + `platform_specific.application_id`; the existing GNOME extension (now accepting both app ids) finds it, hides it from the dash, places/shows/hides it, focus goes to it and typing works. The extension minimizes the popup until `SetVisible(true)`. |
| S3 X11 | **Pass.** The same binary runs on X11 through `iced_winit`/`winit_x11` (Xvfb + openbox): popup window maps, can be moved with `xdotool`, takes keyboard input. Its `WM_CLASS` is the **binary name** (`win11-clipboard-history-iced`), not the app id, so `platform/x11/window.rs` must also match by class of the binary / by window title. |
| S4 emoji | **Fail for colour text, solved with bitmaps.** (Resolution: `src/emoji_image.rs` reads each emoji's PNG out of the bundled CBDT font via cmap + GSUB ligatures; all 1,914 dataset emoji resolve.) Neither the bundled `NotoColorEmoji-CBDT.ttf` nor the system COLRv1 font draws any glyph through iced's text renderer (blank gap, in the nested compositor and on the real GPU). Monochrome fonts render (`Noto Emoji` outline font, ❤ ★ in the UI font). Virtualised grid (only rows near the scroll offset built from `scrollable::on_scroll`, spacers above/below) works with 1,914 emoji. Mitigation to decide: render emoji from pre-rasterised bitmaps (extract the CBDT PNGs, `image` widget / atlas) or accept monochrome. |
| S5 tests | **Pass.** `iced_test::Simulator` builds and runs against the grid view (see test in `src/main.rs`). |
